# GoldAgent

Бот для умеренного внутридневного скальпинга золота (XAUUSD) с ИИ-аналитиком, который разбирает ошибки.

Сделки открывает детерминированный код по правилам с жёстким риск-менеджментом. ИИ (Claude) анализирует журнал сделок и предлагает изменения. Изменение принимается, только если оно прошло бэктест на **реальных** данных и его одобрил человек.

## Статус
Этап 1: данные, бэктест-движок, симулятор брокера с издержками, риск-менеджер, стратегия Session Breakout.

## Установка
```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
```

## Реальные данные
Вариант 1, Dukascopy (бесплатно, минутные bid/ask с 2003 года, реальный спред):
```bash
python -m goldagent download --from 2020-01-01 --to 2025-12-31
```
Вариант 2, история своего брокера из MetaTrader 5 (Сервис → Символы → Бары → M1 → Экспорт):
```bash
python -m goldagent import-mt5 XAUUSD_M1.csv --utc-offset 2   # смещение времени сервера брокера от UTC
```

## Бэктест
```bash
# обучающий период
python -m goldagent backtest --from 2020-01-01 --to 2024-01-01
# out-of-sample проверка
python -m goldagent backtest --from 2024-01-01 --to 2026-01-01
# стресс-тест: удвоенный спред
python -m goldagent backtest --from 2024-01-01 --to 2026-01-01 --spread-mult 2
```
Отчёт сохраняется в `reports/`: сделки (CSV, с контекстом входа для ИИ-разбора) и кривая капитала.

## Ворота перехода к демо-торговле
Out-of-sample после всех издержек: профит-фактор ≥ 1.3, не меньше 200 сделок, просадка ≤ 10%, при удвоенном спреде не уходит в минус.

## Риск (`config/default.yaml`, раздел `risk`, меняет только человек)
0.5% на сделку · дневной лимит 10% или 6 убытков подряд · недельный 15% · kill-switch при просадке 30% от пика.

## Тесты
```bash
pytest
```
`tests/test_real_data.py` (проверка на заглядывание в будущее и детерминированность) запускается, когда скачан `data/XAUUSD_M1.parquet`.
